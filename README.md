# SferaDecompiler: однопроцессный исполняемый IR

Проект генерирует самостоятельный Win32/x86 runtime для структурированного IR. Исходная исполняемая секция PE обнуляется до встраивания. Заголовки, ресурсы и данные загружаются в память самого runtime-процесса.

## Генерация и сборка

Требуются Python 3.10+, Visual Studio 2022 с компонентом Desktop development with C++ и платформа Win32.

```bat
py -3 -m pip install -r requirements.txt
run_sfera.cmd
Sfera\out\build_release.cmd
```

Готовая программа и требуемые DLL появятся в `Sfera\out\bin\Release`. Проект поддерживает ASLR и не резервирует исходный диапазон `0x00400000`.

## Модель памяти

| Область | Реализация |
|---|---|
| Процесс | Один экземпляр сгенерированного runtime |
| Образ | `ProcessMemory` размещает локальный образ через `VirtualAlloc(nullptr, ...)` |
| Адреса данных | PE32 `HIGHLOW`-релокации переводятся от исходной базы к фактической локальной базе |
| Адреса в IR | Генератор помечает адресные immediate/displacement и прямые ветвления; runtime переводит их при чтении операнда |
| EIP и callback | Используются реальные адреса локального образа текущего процесса |
| Стек | `LocalStack` выделяется внутри текущего процесса |
| Импорты | DLL загружаются в текущий процесс, IAT содержит локальные нативные адреса |

`GetModuleHandleA/W(nullptr)` возвращает базу локального образа. `GetModuleFileNameA/W` получает путь исходного клиентского EXE для совместимости с загрузкой ресурсов. Корень клиента определяется по `mbc\_main.mbc`; при необходимости задайте `SFERA_CLIENT_ROOT`.

## Исполнение и диагностика

Рантайм сохраняет GPR, EFLAGS, x87, SSE и виртуальные FS/SEH-данные. Единый x86-мост обслуживает cdecl, stdcall, thiscall, fastcall и callback-вызовы. Перед точкой входа запускается ABI-самопроверка.

Быстрый режим обращается к локальной памяти процесса через единый слой `ProcessMemory`. `SFERA_IR_DEEP_TRACE=1` включает защищённые пробы и запись происхождения изменений. Контролируемая ошибка создаёт `sfera_ir_failure.txt`; нативное падение создаёт `sfera_ir_crash.txt` и `sfera_ir_crash.dmp`.

## Проверки

```bat
py -3 -m unittest discover -s tests -v
```

`Sfera\out\report.json` содержит покрытие IR, результаты CFG-проверок, semantic summaries, число локальных релокаций и адресных операндов. Полная проверка поведения клиента выполняется Release/Win32-сборкой на Windows.
